МАШИННОЕ ОБУЧЕНИЕ

Аннотация: в статье анализируются методы машинного обучения.
Рассматриваются несколько методов, приводятся примеры алгоритмов обучения с преподавателем и без него, а также описываются области применения.
Ключевые слова: машинное обучение, нейронные сети, кластеризация, регрессия, классификация, алгоритм, данные.
Машинное обучение - это категория алгоритмов, которые позволяют программным приложениям более точно прогнозировать результаты без явного программирования.
Основная предпосылка машинного обучения заключается в создании алгоритмов, которые могут принимать входные данные и использовать статистический анализ для прогнозирования результатов по мере поступления новых данных.
Процессы, задействованные в машинном обучении, аналогичны процессам интеллектуального анализа данных и прогнозирующего моделирования.
И те, и другие требуют поиска данных для выявления закономерностей и соответствующей корректировки действий программы.
Многие люди знакомы с машинным обучением по онлайн-магазинам и рекламе, которую они создают.
Это связано с тем, что рекомендательные системы используют машинное обучение для персонализации показа онлайн-рекламы практически в режиме реального времени.
Помимо персонализированного маркетинга, другие распространенные области применения машинного обучения включают обнаружение мошенничества, фильтрацию спама, обнаружение угроз сетевой безопасности, профилактическое обслуживание и создание новостной ленты.
Как работает машинное обучение?
Алгоритмы машинного обучения подразделяются на обучение с преподавателем и без него.
Для обучения с преподавателем требуется специалист по обработке данных, обладающий навыками машинного обучения, который сможет обеспечить как вводные, так и желаемые выходные данные, а также обеспечить обратную связь о точности прогнозов во время обучения алгоритма.
Специалисты по обработке данных определяют, какие переменные или характеристики модели следует проанализировать и использовать для разработки прогнозов.
После завершения обучения алгоритм применит полученные данные к новым данным.
Примерами методов обучения с преподавателем являются классификация и регрессия.
Классификация - самая популярная задача машинного обучения.
Цель этого метода - классифицировать объекты в соответствии с ранее известным признаком, например, документы по языку, музыку по жанру и т.д.
Алгоритм "Наивного Байеса" является классическим примером классификации.
Раньше это использовалось в спам-фильтрах, но теперь это обрабатывается с помощью деревьев решений.
Другой пример классификации - метод опорных векторов, который является самым популярным методом классификации.
Раньше классифицировали все: виды растений, человеческие лица на фотографиях, документы по темам.
Регрессия используется в задачах, когда необходимо предсказать результат.
Регрессия определяется как уравнение, описывающее функцию, которая показывает взаимосвязь между входными и выходными данными.
Этот метод машинного обучения используется для прогнозирования стоимости ценных бумаг, медицинских диагнозов и т.д.
Популярными алгоритмами регрессии являются линейные, полиномиальные, логистические и т.д.
Методы обучения без учителя не требуют готовых ответов и используются для поиска зависимостей между объектами.
К таким методам относятся кластеризация, уменьшение размерности и нейронные сети.
Кластеризация - это метод машинного обучения, при котором объекты разделяются по неизвестному признаку, в то время как алгоритм сам идентифицирует эти признаки.
На сегодняшний день этот метод нашел свое применение в таких задачах, как сжатие изображений, объединение близких точек на карте и т.д.
Наиболее популярными алгоритмами являются метод K-средних и DBSCAN.
Метод уменьшения размерности используется для сбора признаков в абстракции более высокого уровня.
Например, в некоторых исследованиях часто возникает необходимость визуализировать данные для удобства изучения и анализа.
Таким образом, алгебраические функции могут быть представлены в виде графиков функций, статистические выборки могут быть представлены в виде точечных диаграмм.
Трудности возникают, когда необходимо визуализировать многомерные данные, когда каждый объект имеет множество признаков.
Графически такие объекты представляются в виде точки в многомерном пространстве.
Человеку удобно анализировать данные, отображаемые на плоскости, поэтому используются алгоритмы уменьшения размерности.
Примерами таких алгоритмов являются: метод главных компонент, разложение по сингулярным значениям, алгоритм T-SNE.
Сегодня эти алгоритмы используются в рекомендательных системах, тематическом моделировании и т.д.
Нейронные сети используются для решения более сложных задач обработки, чем системы контролируемого обучения, включая распознавание изображений, преобразование речи в текст и создание естественного языка.
Эти нейронные сети работают, комбинируя миллионы примеров обучающих данных и автоматически выявляя тонкие корреляции между многими переменными.
После обучения алгоритм может использовать свой банк ассоциаций для интерпретации новых данных.
Эти алгоритмы стали возможны только в эпоху больших данных, поскольку они требуют огромных объемов обучающих данных.
