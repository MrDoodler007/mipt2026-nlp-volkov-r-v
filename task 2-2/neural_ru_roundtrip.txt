МАШИННОЕ ОБУЧЕНИЕ

Аннотация: в статье анализируются методы машинного обучения.
Рассматриваются несколько методов, приводятся примеры алгоритмов обучения с учителем и без учителя, описываются области применения.
Ключевые слова: машинное обучение, нейронные сети, кластеризация, регрессия, классификация, алгоритм, данные.
Машинное обучение — это категория алгоритмов, которая позволяет программным приложениям более точно прогнозировать результаты без явного программирования.
Основная предпосылка машинного обучения заключается в создании алгоритмов, которые могут получать входные данные и использовать статистический анализ для прогнозирования выходных данных по мере поступления новых данных.
Процессы, связанные с машинным обучением, аналогичны процессам интеллектуального анализа данных и прогнозного моделирования.
Оба требуют поиска закономерностей в данных и соответствующей корректировки действий программы.
Многие люди знакомы с машинным обучением благодаря интернет-магазинам и рекламе, которую они от них получают.
Это происходит потому, что рекомендательные системы используют машинное обучение для персонализации показа онлайн-рекламы почти в реальном времени.
Помимо персонализированного маркетинга, другие распространённые случаи использования машинного обучения включают обнаружение мошенничества, фильтрацию спама, выявление угроз сетевой безопасности, предиктивное техническое обслуживание и создание новостных лент.
Как работает машинное обучение?
Алгоритмы машинного обучения классифицируются на обучение с учителем и без учителя.
Обучение с учителем требует, чтобы специалист по данным с навыками машинного обучения предоставлял как входные, так и желаемые выходные данные, а также обеспечивал обратную связь о точности прогнозов во время обучения алгоритма.
Исследователи данных определяют, какие переменные или характеристики модель должна анализировать и использовать для разработки прогнозов.
После завершения обучения алгоритм будет применять полученные данные к новым данным.
Примерами методов обучения с учителем являются классификация и регрессия.
Классификация — самая популярная задача машинного обучения.
Цель этого метода — классифицировать объекты по заранее известному признаку, например, документы по языкам, музыку по жанрам и т. д.
Классическим примером классификации является алгоритм «Наивный Байес».
Раньше он использовался в спам-фильтрах; сейчас с этим справляются деревья решений.
Другим примером классификации является метод опорных векторов; это самый популярный метод классификации.
Раньше его использовали для классификации всего: видов растений, лиц людей на фотографиях, документов по темам.
Регрессия используется в задачах, где необходимо предсказать результат.
Регрессия задаётся в виде уравнения, описывающего функцию, показывающую связь между входными и выходными данными.
Этот метод машинного обучения используется в: прогнозировании стоимости ценных бумаг, медицинских диагнозах и т. д.
Популярными алгоритмами регрессии являются линейная, полиномиальная, логистическая и т. д.
Методы обучения без учителя не требуют готовых ответов и используются для поиска зависимостей между объектами.
К таким методам относятся: кластеризация, уменьшение размерности и нейронные сети.
Кластеризация — это метод машинного обучения, при котором объекты разделяются по неизвестному признаку, при этом алгоритм сам выявляет эти признаки.
Сегодня этот метод нашёл своё применение в таких задачах, как сжатие изображений, объединение близких точек на карте и т. д.
Самыми популярными алгоритмами являются метод K-средних и DBSCAN.
Метод уменьшения размерности используется для сбора признаков в абстракции более высокого уровня.
Например, в некоторых исследованиях часто необходимо визуализировать данные для удобного изучения и анализа.
Так, алгебраические функции можно представить в виде графиков функций, статистические выборки — в виде диаграмм рассеяния.
Трудности возникают, когда необходимо визуализировать многомерные данные, когда каждый объект имеет множество признаков.
Графически такие объекты представляются как точка в многомерном пространстве.
Человеку удобно анализировать данные, отображаемые на плоскости, поэтому используются алгоритмы уменьшения размерности.
Примерами таких алгоритмов являются: метод главных компонент, сингулярное разложение и алгоритм T-SNE.
Сегодня эти алгоритмы используются в рекомендательных системах, тематическом моделировании и т. д.
Нейронные сети используются для задач более сложной обработки, чем системы обучения с учителем, включая распознавание изображений, преобразование речи в текст и генерацию естественного языка.
Эти нейронные сети работают, объединяя миллионы примеров обучающих данных и автоматически выявляя тонкие корреляции между множеством переменных.
После обучения алгоритм может использовать свой банк ассоциаций для интерпретации новых данных.
Эти алгоритмы стали возможны только в эпоху больших данных, поскольку требуют огромных объёмов обучающих данных.
