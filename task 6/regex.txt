### Full RegEx:
(?:\d{2}[.\-_]\d{2}[.\-_]\d{2,4}|(?:\d{1,2}|(?:перв|втор|треть|четверт|пят|шест|седьм|восьм|девят|десят)\w{1,3})\s(?:января|февраля|марта|апреля|мая|июня|июля|августа|сентября|октября|ноября|декабря)(?:\s\d{2,4})?)

### RegEx breakdown:
(?:
    \d{2}           }
    [.\-_]          }
    \d{2}           } Форматы dd.dd.dd, dd.dd.dddd, dd-dd-dd, dd-dd-dddd
    [.\-_]          }
    \d{2,4}         }
|
    (?:
        \d{1,2}     } Число формата dd или d
    |
        (?:перв|втор|треть|четверт|пят|шест|седьм|восьм|девят|десят)\w{1,3}     } Число словом
    )
    \s
    (?:января|февраля|марта|апреля|мая|июня|июля|августа|сентября|октября|ноября|декабря)   } Месяц словом
    (?:\s\d{2,4})?                                                                          } Год числом dd, ddd, dddd (опционально)
)
